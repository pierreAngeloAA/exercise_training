# Exercise training

Practice exercises from learning JavaScript and Ruby.

| Folder | Content |
|---|---|
| `ejercicios js/clases/` | Class notes: variables, conditionals, loops, functions, arrays, `Map`/`Set`, `this`, callbacks, async, errors, POO; plus small DOM practice pages (to-do list, restaurant menu, prompts) |
| `ejercicios js/ejercicios/` | Short kata-style exercises (lasagna, bird watcher, freelancer rates, high score board, promises…) |
| `ejercicios ruby/` | Ruby katas (Armstrong numbers, bowling, matrix, clock, cipher, Collatz, sieve of Eratosthenes, boutique inventory…) |

## Run

- Ruby: `ruby "ejercicios ruby/<file>.rb"`
- JavaScript: `node "ejercicios js/ejercicios/<file>.js"`, or open the `.html` pages in the browser.
